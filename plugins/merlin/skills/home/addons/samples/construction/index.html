How to use this project dashboard
  1. Open this project's folder in Claude. The Merlin for Construction plugin is required.
  2. Tell Claude what you need, in plain words. Each step below shows the sentence to say when it has nothing yet.
  3. Check the result here. Claude does the work, writes it into the job folder and rebuilds this dashboard.
  4. Approvals happen in Claude. Every email, signature and entry waits for your yes there.
