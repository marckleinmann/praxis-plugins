# Connect this computer

Links this computer to the person's Praxis account. The paid Merlin for Construction plugins only install and run on a connected computer. The work is done by one script that ships with this plugin, `<plugin-root>/scripts/praxis-connect.mjs`. Every command below runs it with `node`.

## Never do these

1. **Never run the `headers` command, and never open, print, copy or quote `~/.praxis/device.json`.** Both hold this computer's key. Claude Code calls `headers` by itself; a person never needs to see it.
2. Never write to `~/.claude/settings.json` yourself. Only the script's `settings --write` writes it, and only after the person says yes in this chat.
3. Never run `unlink` unless the person asked to disconnect this computer.

## Steps

1. **Check first.** Run:

   ```bash
   node "<plugin-root>/scripts/praxis-connect.mjs" status
   ```

   - It says connected, the account is active and the settings entry is in place: tell the person this computer is already connected, to which account, and stop.
   - Connected but the settings entry is missing: go to step 4.
   - Not connected: go on to step 2.

2. **Get a code.** Run:

   ```bash
   node "<plugin-root>/scripts/praxis-connect.mjs" link
   ```

   It prints a code like `ABCD-2345` and an address. Show the person both, the address as a clickable link, and say:

   1. Open the link and sign in with your email, the same way you sign in to the Praxis field app.
   2. Check that the code on the page matches the one here, and that the computer's name looks right.
   3. Press **Connect this computer**.

   The code works for 10 minutes.

3. **Wait for the approval.** Right after showing the link, run this with a 10-minute time limit on the command:

   ```bash
   node "<plugin-root>/scripts/praxis-connect.mjs" link --wait
   ```

   - "Connected": tell the person which account this computer is now linked to.
   - "Still waiting": ask whether they pressed the button, then run the same command again.
   - "expired" or any other message: show the message in plain words and offer to start again from step 2.

4. **Show the settings change, then ask.** Run:

   ```bash
   node "<plugin-root>/scripts/praxis-connect.mjs" settings
   ```

   Show the person the file path and the entry it prints, exactly as printed. Explain in one sentence: this tells Claude Code where the paid Praxis plugins come from, and a copy of the current settings is kept beside it. Ask: "Okay to add this to your Claude Code settings?"

5. **Write it only on a yes.** On a clear yes, run:

   ```bash
   node "<plugin-root>/scripts/praxis-connect.mjs" settings --write
   ```

   On anything else, stop and tell them they can say "connect this computer" again whenever they are ready.

6. **Finish.** Tell the person:

   1. Open a new chat, so Claude Code picks up the Praxis catalog.
   2. In that chat, ask Claude to install your Praxis plugins. Claude runs `claude plugin install <plugin>@praxis-construction` for each plugin Praxis set up for your account, starting with `takeoff`.

## Checking or disconnecting

- **"Is this computer connected?"** Run `status` (step 1) and report what it says in plain words.
- **"Disconnect this computer."** First show what will happen: the key on this computer is deleted, and the Praxis entry comes out of `~/.claude/settings.json`. Ask for a yes. On yes, run:

  ```bash
  node "<plugin-root>/scripts/praxis-connect.mjs" unlink --settings
  ```

  Then tell them to press **Remove** next to this computer on https://app.praxisatwork.com/connect, so the account's list matches.
