# Connect this computer

Links this computer to the person's Praxis account. The paid Merlin for Construction plugins only install and run on a connected computer. The work is done by one script that ships with this plugin, `<plugin-root>/scripts/praxis-connect.mjs`. Every command below runs it with `node`.

## Never do these

1. **Never run the `headers` command, and never open, print, copy or quote `~/.praxis/device.json`.** Both hold this computer's key. Claude Code calls `headers` by itself; a person never needs to see it.
2. Never write to `~/.claude/settings.json` yourself. Only the script's `settings --write` writes it, and only after the person says yes in this chat.
3. Never run `unlink` unless the person asked to disconnect this computer.

## Steps

0. **Check for Node.** Run `node --version`. If it shows v24 or later, go on to step 1.

   If it fails, or shows an older version, connecting cannot work yet. Install Node now, with no yes or no question. First tell the person in one line: "Connecting needs Node, so I'm installing it now. It takes a few minutes, and you quit and reopen the Claude app afterwards." Then run the route for this computer:

   - Windows: `winget install --id OpenJS.NodeJS.LTS -e --source winget`. Tell them to accept any Windows permission window. If `winget` is not found or fails, give them the LTS installer link, https://nodejs.org/en/download.
   - Mac with Homebrew (`brew` runs): `brew install node`.
   - Mac without Homebrew: make a new empty temp folder. Download `SHASUMS256.txt` from https://nodejs.org/dist/latest-v24.x/ and the `.pkg` file it lists into that folder, and check the `.pkg` with `shasum -a 256 -c` against its line. On a match, `open` the `.pkg` and tell them to click through the installer and enter their Mac password. On a mismatch, stop and give the nodejs.org link instead.

   Then tell them to quit and reopen the Claude app fully, start a new chat in the same folder, and say "connect this computer" again. Stop here until `node --version` shows v24 or later.

1. **Check first.** Run:

   ```bash
   node "<plugin-root>/scripts/praxis-connect.mjs" status
   ```

   - It says connected, the account is active and the settings entry is in place: tell the person in one line that this computer is already connected, and to which account. Then go straight on to step 6 in the same reply.
   - Connected but the settings entry is missing: go to step 4.
   - Not connected: go on to step 2. Its closing "Say: connect this computer." line is for someone checking on their own; you are already connecting, so ask the person to type nothing.

2. **Get a code.** Run:

   ```bash
   node "<plugin-root>/scripts/praxis-connect.mjs" link
   ```

   It prints three lines: `Code: <code>`, `Open: <address>` and a line about the 10 minutes.

   **Hard rule: always show the full address from the `Open:` line, word for word, on its own line as a clickable link, every time you show the code.** The address already ends in `?code=<code>`. Copy it exactly as printed; never shorten it, rebuild it, or drop it. A code with no address leaves the person stuck, because the code alone does nothing. If you cannot see the `Open:` line, run `link` again rather than showing the code alone.

   Say this, with the real address and code filled in:

   > Open this page to connect this computer:
   >
   > https://fieldapp.praxisatwork.com/connect?code=ABCD-2345
   >
   > Your code is **ABCD-2345**. You do not need to type it anywhere unless the page asks for it.
   >
   > 1. Open the page and sign in with your email.
   > 2. If the page shows a code box, check it shows the same code as here, then press **Check the code**.
   > 3. Check the computer's name looks right, then press **Connect this computer**.
   >
   > The code works for 10 minutes.

   This code links **this computer** only. It has nothing to do with the Praxis field app on a phone: the field app needs only a sign-in, never a code. Do not mention the field app here.

3. **Wait for the approval.** Right after showing the address, run this with a 10-minute time limit on the command:

   ```bash
   node "<plugin-root>/scripts/praxis-connect.mjs" link --wait
   ```

   While it waits, say one line with the full address again, word for word, as a clickable link: "Waiting for you to press Connect this computer on https://fieldapp.praxisatwork.com/connect?code=ABCD-2345". The person must never have to ask for the address.

   - "Connected": tell the person which account this computer is now linked to.
   - "Still waiting": show the full address again, ask whether they pressed **Connect this computer**, then run the same command again.
   - "expired" or any other message: show the message in plain words and offer to start again from step 2.

4. **Show the settings change, then ask.** Run:

   ```bash
   node "<plugin-root>/scripts/praxis-connect.mjs" settings
   ```

   Show the person the file path and the entry it prints, exactly as printed. Explain in one sentence: this tells Claude Code where the paid Praxis plugins come from, and a copy of the current settings is kept beside it. Ask: "Okay to add this to your Claude Code settings?"

5. **Write it only on a yes.** On a clear yes, run:

   ```bash
   node "<plugin-root>/scripts/praxis-connect.mjs" settings --write
   ```

   Then go straight on to step 6 in the same reply. Connecting is not finished here: the person still needs step 6's words, and nothing else tells him to quit Claude.

   On anything else, stop and tell them they can say "connect this computer" again whenever they are ready.

6. **Finish.** End the reply on the person's exact next move. Say this, word for word, and nothing after it:

   > This computer is connected. Claude reads the new setting only when it starts, so one more step:
   >
   > 1. Quit Claude fully. On a Mac, press Cmd+Q. On Windows, click the small up arrow at the right end of the taskbar, right-click the Claude icon, and choose Quit.
   > 2. Open Claude again.
   > 3. Start a new chat in the same folder.
   > 4. Paste this and send it: **install my Praxis plugins**

## Install the paid tools

When they say "install my Praxis plugins", "install my Praxis tools", "install Merlin for Construction" or "what Praxis tools do I have?". This section never runs `headers` and never opens `~/.praxis/device.json`. "What Praxis tools do I have?" on its own runs only steps 1 and 4 below and installs nothing.

1. **Check the connection.** Run:

   ```bash
   node "<plugin-root>/scripts/praxis-connect.mjs" status
   ```

   If `node` is missing or older than v24, go to step 0 of the steps above.

   - Connected, the account is active and the settings entry is in place: go on to step 2.
   - Not connected, or connected with the settings entry missing: first write this one line to the person, as text, before any other command runs: "This computer is not fully connected to your Praxis account yet, so I'm doing that first." Then go to step 1 of the steps above in the same reply. Ask the person to type nothing: its "Say: connect this computer." line does not apply here.
   - Connected, but it prints a message about the account instead of "Account active": go to step 6 below.
   - It could not reach Praxis: say so in one line, and ask them to say the same words again once the internet is back. Stop.

2. **Read what this account may install.** Run:

   ```bash
   node "<plugin-root>/scripts/praxis-connect.mjs" catalog
   ```

   It prints one line per tool, a name and a version, such as `merlin-for-construction 1.9.0`. It never prints the key. If it prints a message instead of names ("Nothing is set up for this account yet", or a message about the account), go to step 6. Then bring Claude's own copy of the list up to date:

   ```bash
   claude plugin marketplace update praxis-construction
   ```

   If that says `praxis-construction` is not known, Claude has not been restarted since this computer was connected. Say step 6 of the steps above, word for word, and stop.

3. **Install each one.** First run `claude plugin list`. If it shows `takeoff` from `praxis-construction`, run `claude plugin uninstall takeoff@praxis-construction`, because takeoff is now part of Merlin for Construction. Never install `takeoff`, even when step 2 lists it. Then, for each other name from step 2, starting with `merlin-for-construction`, run:

   ```bash
   claude plugin install <name>@praxis-construction
   ```

4. **Check the list yourself.** Run `claude plugin list` and read it. Say what is installed from `praxis-construction`, by its plain name and version: "Merlin for Construction 1.9.0 is installed." A line such as "1 failed" during a step is normal when the step then finishes; mention it only if the person saw one. If a tool from step 2 is not in the list, say which one, in plain words, and show the message its install printed. For "what Praxis tools do I have?" alone, stop here; if nothing from Praxis is installed, say so in one line and that "install my Praxis plugins" installs it.

5. **Finish.** End the reply on the person's exact next move. Say this, word for word, and nothing after it:

   > Next, start a new chat in the same folder, so your new tools load, and paste this: **set up Merlin for Construction**

6. **Nothing to install.** When step 1 or step 2 shows that nothing is set up for this account, or that the account is not active, say what it printed in plain words, then: "Reply to your welcome email and Praxis will sort it out." Install nothing, and stop.

## Checking or disconnecting

- **"Is this computer connected?"** Run `status` (the command in step 1) and report what it says in plain words. Then stop: this check connects nothing and installs nothing.
- **"Disconnect this computer."** First show what will happen: the key on this computer is deleted, and the Praxis entry comes out of `~/.claude/settings.json`. Ask for a yes. On yes, run:

  ```bash
  node "<plugin-root>/scripts/praxis-connect.mjs" unlink --settings
  ```

  Then tell them to press **Remove** next to this computer on https://fieldapp.praxisatwork.com/connect, so the account's list matches.
